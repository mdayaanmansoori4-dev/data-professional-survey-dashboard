# 📊 Data Professional Survey Breakdown

An interactive Power BI dashboard analyzing survey responses from **630 data professionals worldwide** — covering job roles, salaries, programming language preferences, gender pay comparison, and job satisfaction.

## 🔍 Key Insights

- **Salary by Role** — Data Scientists and Data Engineers report the highest average salaries
- **Tech Preferences** — Python is the most widely used programming language by a wide margin
- **Job Satisfaction** — Salary satisfaction (4.27/10) trails work-life balance satisfaction (5.74/10)
- **Gender Pay** — Average salary is nearly balanced across gender (49% vs 51%)
- **Global Reach** — Respondents span Canada, India, the UK, the US, and more

## 📈 Dashboard Features

- KPI cards for total respondents and average age
- Interactive job title and salary breakdown
- Country-wise distribution of survey takers
- Programming language popularity chart
- Gender-based salary comparison (donut chart)
- Work/life balance and salary satisfaction gauges

## 🛠️ Tools Used

- **Power BI Desktop**
- DAX for measures and calculations
